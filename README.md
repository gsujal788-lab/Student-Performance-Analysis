# Student Performance Analysis and Prediction System

## Project Overview
This project uses Python and Machine Learning to analyse student academic performance and predict final mathematics grades based on study time, absences, and previous grades.

## Objectives
- Analyse student academic performance.
- Explore relationships between study habits, absences, and grades.
- Build a Linear Regression model to predict final grades.
- Evaluate the model using standard regression metrics.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Joblib
- Google Colab

## Dataset
The project uses the Student Performance dataset from the UCI Machine Learning Repository.

**Dataset:** Student Performance (Mathematics)

Features used:
- Study time
- Absences
- First-period grade (G1)
- Second-period grade (G2)

Target variable: Final grade (G3)

## Machine Learning Model
Linear Regression was used to predict students' final grades.

### Model Performance
| Metric | Result |
|---|---:|
| Mean Absolute Error (MAE) | 1.31 |
| Root Mean Squared Error (RMSE) | 2.04 |
| Test R² Score | 0.7962 |
| Average 5-Fold CV R² | 0.8292 |
